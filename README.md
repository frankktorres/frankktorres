## What I build

**UNION Platforms** — a health-tech suite for clinics and municipalities (closed source).

| Product | What it does | Status |
|---|---|---|
| **UNION Core / Guard / Trace / Senior** | Clinical-pharmaceutical decision support (CDSS): rule engine driven by curated, source-graded clinical knowledge, with audit trail and role-based access | In production |
| **UNION Pharmasense** | B2G pharmaceutical surveillance for municipalities: population-level outbreak detection (Farrington-family algorithms) over dispensing data | Active development |
| **UNION Senior** | Outcomes platform for geriatric care: longitudinal scores from validated instruments, metadata-driven improvement / stable / decline engine, cohort analytics for clinicians, managers and researchers | In construction |

Co-developed within the Pharmaceutical Sciences graduate program at UFPR. Both programs are registered at INPI (Brazilian PTO); rights holder: UFPR.

| Program | What it does | Stack | INPI |

## How I work

- **Privacy by design:** LGPD-aware data models, pseudonymization, synthetic data for development, anonymized research exports
- **Evidence-first:** clinical rules ship only with graded sources; no number without a reference
- **Engineering hygiene:** typed Python, versioned migrations, CI, ADRs, test-gated merges
- **AI-assisted delivery:** autonomous coding agents running nightly backlogs under guardrails (CI, review agents, human sign-off on clinical rules)
